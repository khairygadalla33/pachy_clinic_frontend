# Pachy Clinic - Frontend Management System

Aesthetic & Laser Clinic Management System frontend built with React, TypeScript, TailwindCSS, and Vite.

## Production Cloud Deployment
- **Live URL:** https://pachy.deboura.com
- **Backend API:** https://clinic.deboura.com/api
- **Deployment Platform:** Oracle Cloud (Docker + Nginx)
- **CI/CD:** Automated GitHub Actions on push to `main`
